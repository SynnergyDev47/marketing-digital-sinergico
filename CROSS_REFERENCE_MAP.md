# Mapa de relaciones y referencias cruzadas

## Regla principal

Una referencia editorial ayuda a comprender o navegar. Un CTA pide una acción comercial. Cada ebook tiene un solo CTA principal, aunque pueda mencionar otros volúmenes cuando el contexto lo exija.

## CTA principal por ebook

| Ebook de origen | CTA principal | Razón |
|---|---|---|
| Domina el Marketing Digital | Marca Magnética | Convertir fundamentos en diferenciación y significado reconocible |
| Relanza tu Emprendimiento | El Gran Túnel | Integrar las correcciones en un sistema comercial coherente |
| 10 Claves para Vender Más | El Cliente Encantado | Extender confianza, reducción de fricción y seguimiento después de la compra |
| Marca Magnética | El Gran Túnel | Conectar la promesa de marca con el recorrido comercial |
| Equipos Imparables | El Gran Túnel | Integrar roles y handoffs en el sistema completo |
| El Cliente Encantado | El Gran Túnel | Conectar adquisición, venta, experiencia y retención |
| El Gran Túnel | Diagnóstico profesional de Synnergy Lab | Adaptar el sistema al negocio real |

## Relaciones conceptuales permitidas

- `Domina` puede referir a todos los volúmenes como profundizaciones, sin explicarlos.
- `Relanza` refiere a `Marca` cuando el problema sea diferenciación, a `Equipos` cuando sea ejecución y a `Gran Túnel` cuando sea integración.
- `10 Claves` refiere a `Marca` o `Relanza` cuando la fuga no pueda corregirse tácticamente y a `Cliente` cuando continúe después de la compra.
- `Marca`, `Equipos` y `Cliente` pueden referirse entre sí cuando promesa, ejecución y experiencia se condicionen mutuamente.
- `El Gran Túnel` refiere a los seis volúmenes como fuentes de profundidad.

## Forma editorial

- Explicar en una o dos frases por qué el otro volumen es relevante.
- No insertar un CTA secundario con el mismo peso visual que el principal.
- No afirmar que el lector está obligado a seguir el orden comercial.
- No utilizar referencias como excusa para omitir una explicación indispensable.
- En la edición preparada para IA, usar el título y el `ebook_id` cuando esté disponible.
