# Decisiones editoriales

Este documento es la fuente de verdad del proyecto. Si otro rector lo contradice, prevalecen estas decisiones hasta que Aurelio Crespo apruebe y registre una sustitución.

## Identidad del producto

- El ecosistema está formado por siete ebooks conectados, pero cada volumen puede leerse de manera independiente.
- Orden comercial: `Domina` → `Relanza` → `10 Claves` → `Marca` → `Equipos` → `Cliente` → `El Gran Túnel`.
- Los títulos cortos quedan fijados; los subtítulos se validan durante el plan SEO de cada volumen.
- Autoría: **Aurelio Crespo, fundador de Synnergy Lab**.
- Synnergy Lab funciona como sello editorial y como proveedor del diagnóstico profesional final.
- Los tres primeros ebooks son recursos gratuitos completos y de alta calidad.
- Los cuatro últimos son productos de pago. Solo los productos de pago se preparan para Hotmart y Amazon Kindle.
- No existen precios aprobados. Cualquier precio futuro exige investigación y decisión independiente.

## Mercado y lector

- Mercado editorial principal: Latinoamérica hispanohablante.
- Cuba recibe adaptación explícita cuando el tema y la evidencia lo justifican.
- Florida y los negocios latinos en Estados Unidos son contexto secundario.
- España no es mercado comercial objetivo, aunque pueden utilizarse fuentes españolas o europeas de calidad cuando sean transferibles.
- Lector central: propietario u operador de una micro o pequeña empresa con actividad real o lanzamiento avanzado, conocimientos básicos o intermedios, recursos limitados y responsabilidad directa sobre marketing o ventas.

## Voz y tratamiento

- Voz: mentor estratégico y aliado que desafía creencias con evidencia.
- Segunda persona singular (`tú`) como tratamiento habitual.
- Tercera persona para instituciones, datos, casos y categorías empresariales.
- La disrupción se utiliza solo cuando una creencia real bloquea el aprendizaje.
- Puede ridiculizarse una creencia, contradicción o mala práctica; nunca al lector, una persona, un colectivo o un competidor.
- Se evitan catastrofismo, promesas garantizadas, hipérbole y motivación vacía.
- El contenido adopta la calidad verbal de Synnergy Lab, pero no traslada automáticamente sus afirmaciones corporativas o comerciales.

## Conocimiento y evidencia

- Cada ebook parte de investigación profunda, una matriz de evidencia y fuentes recuperables.
- No se admiten en la versión final citas dependientes de una conversación, como identificadores `turn...`, sin URL, DOI o referencia bibliográfica estable.
- Las afirmaciones se clasifican internamente como hecho verificado, dato volátil, inferencia, recomendación, ejemplo o hipótesis.
- La evidencia se integra sin convertir el ebook en un artículo académico: notas numéricas solo donde hagan falta y sección `Fuentes y notas del capítulo` con enlaces limpios al cierre de cada capítulo.
- Una nota puede respaldar un párrafo o una unidad argumental inequívoca; se evita la sobrecitación.
- Se eliminan parámetros UTM y otros rastreadores prescindibles de los enlaces publicados.
- Las fuentes permanecen en su repositorio original; los documentos derivados las enlazan y no las duplican.
- Los tres primeros alcances se cierran a partir de sus investigaciones actuales. Los libros 4–7 permanecen provisionales hasta completar sus investigaciones.
- No se utilizan como casos Luminare/Luminares ni Mr Fox.

## Arquitectura pedagógica y comercial

- Viaje conceptual: fundamentos → diagnóstico y foco → corrección de fugas → especialización en marca, equipo o experiencia → integración.
- No hay una secuencia obligatoria de lectura.
- Cada ebook contiene un solo CTA comercial principal; puede incluir referencias editoriales secundarias que no compitan con ese CTA.
- Los ebooks gratuitos no ocultan pasos esenciales. Los pagados se diferencian por profundidad, herramientas, integración y capacidad de implementación sostenida.
- `El Gran Túnel` puede resumir conceptos imprescindibles, pero no duplicar capítulos completos.

## Preparación para inteligencia artificial

- El ecosistema debe poder utilizarse como una base de conocimiento curada para trabajar con IA.
- Su valor no consiste en acumular información, sino en seleccionar, verificar, relacionar, contextualizar y convertir evidencia dispersa en decisiones aplicables.
- Cada producto tendrá una edición humana y una fuente estructurada apta para recuperación y uso con IA.
- La preparación para IA no autoriza a inventar hechos, eliminar matices, sustituir el criterio profesional ni presentar salidas de un modelo como evidencia.
- El contenido público enseña un ciclo conceptual neutral —diagnóstico → decisión → ejecución → medición → aprendizaje— y no revela ni atribuye como propia una metodología interna no aprobada.

## Implementación y control

- Se actualizan primero los rectores y después se inicia `Domina el Marketing Digital`.
- Flujo por ebook: investigación validada → matriz de afirmaciones y fuentes → SEO → plan de contenidos → aprobación → redacción → control de calidad → exportación.
- El primer capítulo de `Domina` calibra la voz; después se trabaja en bloques de dos o tres capítulos.
- Extensiones orientativas: gratis 10.000–15.000 palabras; pagados especializados 25.000–35.000; `El Gran Túnel` 40.000–55.000, con margen de ±10 % cuando el contenido lo justifique.
- Las notas numéricas se reinician por capítulo; cada capítulo termina con sus fuentes y notas, y cada volumen con una bibliografía consolidada.
- El repositorio se actualiza mediante Git y cada cambio editorial estructural debe cerrarse con un commit que explique qué se modificó y con qué objetivo.
